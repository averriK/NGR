# PLAN-quarto-yaml

## Objective

Implement reusable Quarto helper functions in NGR so R callers can use
qrt-style runtime YAML behavior and dynamic QMD block composition without
shelling out to qrt runtime scripts.

- NAMESPACE exports for the new API
- DESCRIPTION only if imports/vignette metadata need adjustment

## Out Of Scope

- No qrt runtime changes.
- Do not add new `inst/examples` content for this migration. Follow
  gmsp/newmark: vignettes plus pkgdown.
- Do not delete `inst/examples` until its useful content is represented in
  vignettes/pkgdown.
- Do not treat tests alone as sufficient documentation; update README and pkgdown/vignette surfaces.
- No replacement of qrt scripts.
- No dependency on qrt.
- No psha scaffold changes from the NGR documentation migration.
- No rewrite of plotting/table helpers while migrating their manual docs pages
  into pkgdown articles.
