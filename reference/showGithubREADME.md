# Display GitHub README as iframe

Display GitHub README as iframe

## Usage

``` r
showGithubREADME(repo, user = "averriK", height = "500px")
```

## Arguments

- repo:

  Repository name (e.g., "gmsp", "kashima")

- user:

  GitHub username (default "averriK")

- height:

  Height of iframe (default "500px")

## Value

Prints iframe HTML using cat() for results: asis
