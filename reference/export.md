# Export Highcharts widget to PNG

Export Highcharts widget to PNG

## Usage

``` r
export(
  hc,
  width = NULL,
  height = NULL,
  page_width = 8.27,
  page_height = 11.69,
  factor_width = 1,
  factor_height = 1/2,
  dpi = 96,
  filename = "plot.png",
  delay = 0.5
)
```

## Arguments

- hc:

  htmlwidget object

- width:

  numeric

- height:

  numeric

- page_width:

  numeric default 8.27 inches (A4)

- page_height:

  numeric default 11.69 inches (A4)

- factor_width:

  numeric default 1. Full width

- factor_height:

  numeric default 1/2. Half page

- dpi:

  numeric default 96

- filename:

  character default "plot.png"

- delay:

  numeric default 0.5
