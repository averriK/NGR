# NGR

**Next Generation Reporting**

R package for generating professional multi-format reports with advanced plotting (highcharter / ggplot2) and table formatting (flextable, gt, kableExtra). Integrates Quarto for HTML / PDF / DOCX rendering with configurable templates.
